### **4. Setup Guide (SETUP.md)**

```markdown
# Setup Instructions

## Prerequisites
- Node.js 18+
- npm or yarn
- Supabase account
- Cloudinary account
- Google Cloud account (for Fit API)

## Step 1: Clone Repository
```bash
git clone [repo-url]
cd Weightloss
npm install
```

## Step 2: Environment Variables
Create `.env` file:
```
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_anon_key
VITE_GOOGLE_CLIENT_ID=your_google_client_id
# ... etc
```

## Step 3: Database Setup
1. Go to Supabase SQL Editor
2. Run `database/schema.sql`
3. Run `database/create_google_fit_table.sql`

## Step 4: Configure OAuth
1. Google Cloud Console: Enable Fit API
2. Supabase: Add Google provider
3. Set redirect URLs

## Step 5: Deploy
```bash
npm run build
# Deploy to Cloudflare Pages
```

## Step 6: Add Environment Variables
Add all env vars to Cloudflare Pages dashboard

## Estimated Setup Time: 2-4 hours
```

## 🚨 **Legal Considerations:**

### **What to Include in Sale Agreement:**

1. **Transfer of Ownership**
   - Source code
   - Database
   - Domain name
   - Brand assets

2. **Support Terms**
   - 1-2 weeks deployment support
   - Bug fixes during transition
   - Knowledge transfer

3. **Payment Terms**
   - Amount and schedule
   - Escrow (recommended for large amounts)
   - Refund policy (if any)

4. **Non-Compete** (Optional)
   - Won't build competing product for X months
   - Geographic restrictions

5. **Warranties**
   - Code is original (not copied)
   - No legal issues
   - All dependencies properly licensed
